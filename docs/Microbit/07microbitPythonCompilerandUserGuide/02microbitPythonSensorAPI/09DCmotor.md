# DC_motor
 A DC motor is an electric motor driven by direct current (DC). It generates rotational motion through the interaction between the rotating rotor and the adjacent magnetic poles, causing the rotor to cut through the magnetic field lines.  



## Notes
+ The DC motor interface consists of two wires and has no polarity requirement. During operation, the rotation direction can be controlled by the program or changed by reversing the connection of the interface.  
+ The motor speed is controlled by the PWM duty cycle generated by the controller. However, since this DC motor module does not have a feedback system, the actual motor speed cannot be detected. Therefore, advanced control functions, such as precise speed control and torque control, cannot be implemented.

## Parameter Macros
```python
M1 
M2 
M3 
M4 
```

 These macros are used for port selection when creating an object.  



## Class   motor
The `motor` object is the basic object used to control a single motor.



### Constructor
```python
class DC_motor.motor(port)
```

Create a single-motor object from the files in `DC_motor`.



**Parameters**

+ port 
    - M1
    - M2
    - M3
    - M4

> The selected port corresponds to the port connected to the micro. Connect the motor to the port on the micro with the corresponding silkscreen label.
>



### Functions
#### run
+ run(velocity)

Set the Motor Speed



**Parameters**

+ velocity 

> range  -255 ~ 255
>



**Usage Examples：**

```python
from microbit import *

import DC_motor # Import the DC Motor Library.

dcm = DC_motor.motor(DC_motor.M1) # Create a single-motor handle and specify the port asM1

dcm.run(150) # Set the Motor Speed
while True:
    pass
```





## Class   motor_pair
The motor_pair object is the basic object used to control two motors.  



### Constructor
```python
class DC_motor.motor_pair(port1, port2)
```

Create a dual-motor object from the files in `DC_motor`.



**Parameters**

+ part1  Left Motor Port  
+ part2  Right Motor Port  

> Both parameters can be set to `M1`, `M2`, `M3`, or `M4`. When using this function, the two parameters shall be set to different ports.
>



### Functions
#### move
+ move( velocity1, velocity2)

 Set the speed of the two motors independently.  



**Parameters**

+ velocity1      Left Motor speed
+ velocity2      Right Motor speed

>  Speed Range:   -255 ~ 255
>



**Usage Examples：**

```python
from microbit import *

import DC_motor # Import the DC Motor Library.

 # Create a single-motor handle and specify the ports as M1 and M2, respectively.
dcmp = DC_motor.motor_pair(DC_motor.M1, DC_motor.M2)

dcmp.move(150， -150) # Set the Speed of the Dual Motors.
while True:
    pass
```
